Генератор ключей

Команда, которая будет выполнена на сервере Minecraft при использовании ключа.
Команда Minecraft:
Репозиторий должен существовать. Если его нет, сначала создайте репозиторий на GitHub.
Требуется личный токен доступа с правами на репозиторий. Создать токен
Необходимые разрешения: repo (для приватного репозитория)
Для публичного репозитория: public_repo
Срок действия токена: установите подходящий срок
Внимание: Токен имеет доступ к вашему репозиторию.

Частые проблемы и решения:

  • Ошибка 401 - Неверный токен или недостаточно прав. Убедитесь, что токен правильный.
  • Ошибка 404 - Репозиторий или файл не найден. Проверьте данные.
  • Ошибка 403 - Превышены лимиты GitHub API или нет доступа.
  • Ключи не отображаются - После сохранения может потребоваться время для обновления.
